03

        
Add Snippet to Your Website

        
Paste this into your website's <head> tag.

        

          
          
<!-- SiteAgent AI Chatbot -->
<script>
  window.SiteAgent = {
    token: "sa_pub_v1_YOUR_FULL_TOKEN_HERE",
    position: "bottom-right",
    theme: "auto"
  };
</script>
<script
  src="https://cdn.jsdelivr.net/gh/Webexguru-Hasan/siteagent-widget@v1.0.3/siteagent.js"
  async>
</script>
<!-- End SiteAgent -->

        

        

          ⚠️ If the snippet is not working, try removing async from the script tag.

Platform-Specific Instructions

        
Step-by-step for every major platform

        
        

          

            
WordPress+

            

              
1. Go to Appearance > Theme File Editor > header.php

              
2. Paste the snippet right before the closing </head> tag

              
3. Update File

            

          

          

            
Shopify+

            

              
1. Go to Online Store > Themes > Edit code

              
2. Open theme.liquid

              
3. Paste the snippet before </head>

              
4. Click Save

            

          

          

            
Webflow+

            

              
1. Go to Project Settings > Custom Code

              
2. Paste into the Head Code section

              
3. Save Changes and Publish

            

          

          

            
Wix+

            

              
1. Go to Settings > Advanced > Custom Code

              
2. Click + Add Custom Code

              
3. Paste the snippet, set to load on All Pages, in the Head

              
4. Click Apply

            

          

          

            
Squarespace+

            

              
1. Go to Settings > Advanced > Code Injection

              
2. Paste snippet into the Header box

              
3. Save

            

          

          

            
React / Next.js+

            

              
Add the scripts to your _document.js or layout component inside the Head component.

            

          

          

            
Plain HTML+

            

              
Simply copy and paste the snippet directly into your <head> tag.

            

          

        

      

    


    
    

      

        
Customize Your Chatbot

        
Match your brand with these optional settings.


        

          
          
<script>
  window.SiteAgent = {
    token: "sa_pub_v1_YOUR_TOKEN",
    position: "bottom-right", // bottom-right, bottom-left
    theme: "auto", // auto, light, dark
    primaryColor: "#00D4FF", // any valid CSS color
    greeting: "👋 Hi! Ask me anything...",
    placeholder: "Type a message...",
    leadCapture: true // enables asking for email after 2 messages
  };
</script>

        


        

          

            
              

                Property
                Type
                Default
                Description
              

            
            
              

                token
                String
                (Required)
                Your unique widget token.
              

              

                position
                String
                bottom-right
                Sets chatbot position.
              

              

                theme
                String
                auto
                auto matches system pref. light or dark forces theme.
              

              

                primaryColor
                String
                #000000
                Accent color for headers, bubbles, and send button.
              

              

                greeting
                String
                "👋 Hi..."
                Initial message shown to users.

Troubleshooting

        
        

          

            
Chat bubble is not appearing+

            

              
Verify that your snippet is placed correctly in the <head> tag and your token is valid.

            

          

          

            
"Could not extract content" error+

            

              
Your website might be blocking bots. Ensure your robots.txt allows generic crawlers.

            

          

          

            
Chatbot is giving wrong or outdated answers+

            

              
You can force a manual re-crawl using our API.

              

                
                
curl -X POST https://wazidhasan-siteagent-mcp.hf.space/api/recrawl -H "x-api-key: YOUR_API_KEY"

              

            

          

          

            
"Sorry, something went wrong"+

            

              
This usually indicates a temporary server issue. Check the server status below.

            

          

          

            
Rate limit reached+

            

              
You have exceeded your plan's monthly requests. Please upgrade your plan on MCPize.
