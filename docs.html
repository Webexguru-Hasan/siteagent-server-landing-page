Add Snippet to Your Website

        
Paste this into your website's <head> tag.

        

          
          
<!-- SiteAgent AI Chatbot -->
<script>
  window.SiteAgent = {
    token: "sa_pub_v1_YOUR_FULL_TOKEN_HERE",
    position: "bottom-right",
    theme: "auto"
  };
</script>
<script
  src="https://cdn.jsdelivr.net/gh/Webexguru-Hasan/siteagent-widget@v1.0.5/siteagent.js"
  async>
</script>
<!-- End SiteAgent -->

        

        
⚠️ If the snippet is not working, try removing async from the script tag.


        
Done!

        
Refresh your website. The chat bubble appears in the bottom-right corner.

Platform-Specific Instructions

        
Step-by-step guides for common website builders.


        

          
🔵 WordPress+

          

            
Option A — No coding (recommended):

            
    
              
  1. Install the free plugin "Insert Headers and Footers"
    2. 
              
  2. Go to Settings → Insert Headers and Footers
    3. 
              
  3. Paste the snippet into the Scripts in Footer section
    4. 
              
  4. Click Save
    5. 
            

            
Option B — Manual:

            
    
              
  1. Go to Appearance → Theme Editor → open header.php
    2. 
              
  2. Paste the snippet just before the closing </head>
    3.

    4.

Troubleshooting


        

          

            Chat bubble is not appearing
            +
          

          

            
    
              
  1. Press F12 → click the Console tab
    2. 
              
  2. Look for red error messages
    3. 
              
  3. Ensure the snippet is inside your <head> tag
    4. 
              
  4. Check that there are no extra spaces or line breaks in the token
    5. 
              
  5. Try a hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
    6. 
            

          

        


        

          

            "Could not extract content" error
            +
          

          

            
The chatbot could not read your website. Check that:

            
    
              
  • Your page has at least 30 words of visible text
    • 
              
  • Your website is publicly accessible (not behind a login)
    • 
              
  • Your site does not require JavaScript to render content
    • 
            

          

        


        

          

            Chatbot is giving wrong or outdated answers
            +
          

          

            
Trigger a manual re-crawl:

            PowerShell
            

              
              
Invoke-RestMethod -Uri "https://wazidhasan-siteagent-mcp.hf.space/api/crawl" -Method POST -Headers @{"Content-Type"="application/json"} -Body '{"token":"YOUR_FULL_TOKEN","force":true}'

            

            cURL
            

              
              
curl -X POST https://wazidhasan-siteagent-mcp.hf.space/api/crawl -H "Content-Type: application/json" -d '{"token":"YOUR_FULL_TOKEN","force":true}'
