Generate Your Widget Token

Run one command with your API key and website URL. Your unique token is returned instantly.

bash 
curl -X POST \
  https://wazidhasan-siteagent-mcp.hf.space/api/token \
  -H "Content-Type: application/json" \
  -d '{ "apiKey": "YOUR_API_KEY",
    "siteUrl": "https://yoursite.com" }'
→
3

Paste One Snippet & Done

Add one script tag before your closing </body> tag. The chatbot appears instantly.

html

  src="https://cdn.jsdelivr.net/gh/

@v1.0.3/siteagent.js"
  data-token="YOUR_TOKEN"
></script>

✦  FAQ

          
Frequently Asked Questions

          
Everything you need to know before getting
              started.

        


        


          

            

              Do I need coding skills to use SiteAgent?
              +
            

            

              No coding skills required. Just copy and paste one snippet into your website's head section. If you can
              edit a webpage, you can install SiteAgent.
            

          


          

            

              How long does setup take?
              +
            

            

              Under 5 minutes. Subscribe on MCPize, generate your token with one command, paste the snippet — done. The
              chatbot goes live instantly.
            

          


          

            

              What website platforms does it work on?
              +
            

            

              SiteAgent works on every platform — WordPress, Shopify, Webflow, Wix, Squarespace, React, Next.js, and
              plain HTML. Any site that allows custom code in the head section is supported.
            

          


          

            

              Does the chatbot need manual training?
              +
            

            

              No. SiteAgent automatically crawls and reads your website content. There is no manual training, no
              uploading documents, and no configuration required. It learns from your site directly.
            

          


          

            

              What happens if my website content changes?
              +
            

            

              SiteAgent re-crawls your website automatically. Free plan re-crawls weekly, Pro re-crawls daily, and
              Agency re-crawls hourly. You can also trigger a manual re-crawl anytime via the API.
            

          


          

            

              Is there a free plan with no credit card required?
              +
            

            

              Yes. The Free plan gives you 200 requests per month and crawls up to 10 pages — completely free, no credit
              card required. Upgrade anytime when you need more.
            

          


          

            

              How do I get my MCPize API key?
              +
            

            

              Go to mcpize.com/mcp/siteagent-server, choose any plan including Free, and your API key is shown
              immediately after signup. Save it — you will need it to generate your widget token.
