How to Add a Free AI Chatbot to WordPress or Shopify

In the fast-paced world of digital business, your visitors don't want to wait hours for a support ticket response. They want answers now. This guide will show you how to set up SiteAgent—the ultimate no-coding AI chatbot—on your website in record time.

Traditional chatbots often frustrate users with rigid "if-this-then-that" trees. SiteAgent is different. It uses Auto-crawl technology to read your entire website, turning your existing content into a brain for your AI assistant. Whether you use WordPress, Shopify, or a custom builder, here is exactly how to get it done.

Step 1: Get Your MCPize API Key

Before you can generate a chatbot widget, you need to subscribe to the SiteAgent server. SiteAgent is hosted on the MCPize marketplace, which handles the AI infrastructure for you.

  1. Go to mcpize.com/mcp/siteagent-server.
  2. Choose a plan. The Free Plan is perfect for starters, offering 200 requests/mo and up to 10 pages crawled.
  3. After signing up, your MCPize API Key (starting with sk_) will be shown on the screen.
💾 Pro Tip: Save this key securely. You will need it to generate your unique widget token in the next step.

Step 2: Generate Your Widget Token

Your token is the unique identifier that links the chatbot widget to your specific website content. You have two ways to generate this:

Option A: Using the Landing Page (Easiest)

  1. Scroll down on the SiteAgent Landing Page to the "Generate Token" section.
  2. Paste your sk_ API Key and enter your website's URL (e.g., https://yoursite.com).
  3. Click Generate My Token →. The tool will provide you with a ready-to-use script snippet.

Option B: Using Terminal (For Developers)

If you prefer using the command line, you can generate a token using cURL or PowerShell:

# cURL Command
curl -X POST https://wazidhasan-siteagent-mcp.hf.space/api/token \
     -H "Content-Type: application/json" \
     -H "x-api-key: YOUR_MCPIZE_API_KEY" \
     -d '{"website_url":"https://yourwebsite.com"}'

Step 3: Platform-Specific Installation

Now that you have your snippet, it's time to paste it into your website. SiteAgent works everywhere, but the "how" varies slightly by platform.

WordPress AI Chatbot Setup

For WordPress, the most reliable method is using the "Insert Headers and Footers" plugin:

  • Install the plugin from the WordPress repository.
  • Go to Settings → Insert Headers and Footers.
  • Paste your SiteAgent snippet into the Scripts in Footer section and save.
  • Manual method: Paste the code just before the </head> tag in your header.php file.

Shopify AI Chatbot Setup

Adding AI to your Shopify store helps answer product questions instantly:

  • Go to Online Store > Themes > Actions > Edit Code.
  • Locate the theme.liquid file under the Layout folder.
  • Paste the snippet just before the closing </head> tag and click Save.

Other Builders (Wix, Webflow, Squarespace)

SiteAgent is fully compatible with these platforms as well:

  • Webflow: Go to Project Settings > Custom Code and paste the snippet in the Head Code section.
  • Wix: Go to Settings > Custom Code, click "+ Add Custom Code", paste the snippet, and set "Place Code in" to Head.
  • Squarespace: Go to Settings > Advanced > Code Injection and paste into the Header box.

Step 4: Customizing Your Assistant

Don't settle for the defaults. You can customize your AI customer support widget by adding properties to the window.SiteAgent object in your script:

Property Description Example
primaryColor Match your brand color. "#2563EB"
greeting The first message users see. "Welcome! How can I help?"
leadCapture Automatically collect emails. true
position Screen placement. "bottom-left"

Troubleshooting Common Issues

If your chatbot widget isn't appearing as expected, check these common fixes found in our documentation:

  • Bubble not appearing? Press F12 to check for console errors. Ensure your token is correct and that the script is within the <head> tag.
  • Outdated answers? SiteAgent re-crawls automatically (weekly on Free, daily on Pro). You can trigger a manual re-crawl using the API if you've recently updated your content.
  • "Could not extract content"? Make sure your site is public and has at least 30 words of readable text. SiteAgent needs content to "learn" from!
⚠️ Note: If the snippet isn't working on your specific platform, try removing the async attribute from the script tag.
